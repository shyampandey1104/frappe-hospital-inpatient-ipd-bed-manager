# Frappe Hospital IPD Ward Bed Manager & Cashless TPA Engine

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Healthcare](https://img.shields.io/badge/Healthcare-NABH%20Compliant-blue.svg)](https://frappehealth.com)

NABH-ready hospital In-Patient Department (IPD) bed occupancy management, ward transfers, and Third-Party Administrator (TPA) cashless insurance pre-authorization billing.

## Features
- **Ward Bed Registry:** Real-time occupancy tracking across ICU, Deluxe, Semi-Private & General wards.
- **TPA Pre-Auth Split:** Cashless insurance authorization limit vs. patient co-pay settlement.
- **NABH Audit Records:** Complete admission-to-discharge cycle timestamps and clinical ledger.

## Installation & Tests
```bash
python3 -m unittest discover tests
```
